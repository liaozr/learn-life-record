顶背离的核心定义 当价格创出更高高点，而MACD对应的高点没有同步创出更高高点，反而降低时，就形成了顶背离。 例如： 股价： A = 10元 B = 15元 C = 20元 A < B < C MACD： A = 1.5 B = 1.2 C = 0.8 A > B > C 这就是标准顶背离。 不分个股、板块、指数 理论上都适用： 个股 行业板块指数 大盘指数 ETF 例如： 上证指数 创业板指 半导体板块指数 券商板块指数 都可以观察MACD背离。 因为MACD本质上反映的是趋势动能，而不是某个特定品种的专属指标。 日线、周线、月线都可以 但意义不同。 周期 含义 30分钟 短线调整 60分钟 短线波段 日线 中短期调整 周线 中期趋势变化 月线 长期趋势变化 一般来说： 周期越大，背离的参考价值越高。 所以： 日线顶背离，可能跌几天到几周。 周线顶背离，可能跌几个月。 月线顶背离，甚至对应几年级别的调整。 但有一个重要前提：高点要有可比性 这是很多人容易犯错的地方。 错误例子 股价： 10元 ↓ 15元 ↓ 15.2元 MACD： 1.5 ↓ 1.2 ↓ 1.0 虽然严格来说也是价格新高、MACD新低， 但15元和15.2元的差距太小， 这种往往没有太大分析价值。 有效背离 价格： 10 →15 →20 而MACD： 1.5 →1.0 →0.5 价格明显创新高， MACD明显走弱， 这种背离更值得关注。 MACD看哪个高点？ 实战中有三种看法： DIF线高点（最常见） MACD柱状图高点 DIF和柱状图同时确认（较严格） 很多老交易员更重视： DIF高点背离 + 红柱面积缩小 因为这样假信号较少。 所以更准确的表述应该是 在明显上升趋势中，如果价格连续创出更高高点，而MACD对应高点持续降低，就构成顶背离；周期越大（周线、月线）和背离次数越多（双顶、ABC三重顶）， 后续出现调整或趋势转弱的概率通常越高。 不过要注意： 顶背离只是“动能减弱”的证据，不是“马上下跌”的命令。 很多强势股会出现： 顶背离 → 横盘数周 → 再涨一段 → 最后才下跌 因此实战上通常会结合： MACD死叉 跌破重要均线（20周线、60日线等） 放量下跌 前低被跌破 来确认背离是否真正转化为趋势下跌
